GCC High vs. Azure Commercial — Service Parity Map

What's available, what's not, and what works differently in the sovereign cloud. Verified against Microsoft documentation and production GCC High deployments.

✓ Available — Generally Available in GCC High
~ Partial — Available with limitations or feature gaps
✗ Not Available — Not in GCC High as of this publication
⚠ Service availability changes with Microsoft releases. Always verify current status at Microsoft Learn — GCC High and DoD before architecture or licensing decisions. Updated May 2026. Verify changes via the GCC High Roadmap Tracker.

Critical Endpoint Differences

Every integration, app registration, and API call must target GCC High endpoints — not commercial. Using commercial endpoints in a GCC High tenant fails silently or routes data incorrectly.

Identity & Access Management
